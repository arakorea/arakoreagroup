NOTE ON MULTILINGUAL SEARCH
The site intentionally uses one HTML page per section with a client-side language switch. Search engines may primarily index the default rendered language. True language-targeted indexing would normally require separate crawlable locale URLs/pages. This FINAL build does not create duplicate locale pages because the project requirement is to keep one maintainable page per section.
